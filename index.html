FAQ

Quick answers.

Where do I get a key?

Keys are free in the Discord: discord.gg/8TgCqcyJtn. Paste it into the key field and press Activate.

Windows Defender flagged it.

It's an unsigned executable. Add the .exe to your exclusions, then download it again if Windows removed it.

Attach does nothing.

Make sure Roblox was launched from roblox.com and you're inside a game (not the menu). Close any other executor first — they use the same local port.

Does it work after a Roblox update?

The engine needs to be updated for each new Roblox build. Updates are dropped in the Discord.
